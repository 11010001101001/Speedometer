## ✨ Features

- **HUD Mode**: Windshield reflection projection mode with mirrored display and high contrast.
- **Real-Time Speed Tracking**: Precise GPS-based speed calculation via CoreLocation.
- **Speed Limit Alerts**: Configurable maximum speed thresholds with distinct audio warnings.
- **Eco Range Indicator**: Dedicated fuel economy bracket visualization.
- **Driver Fatigue Timer**: Configurable break reminders for long road trips.
- **Live Weather**: Integrated weather conditions and ambient temperature display.
- **SwiftData Persistence**: Instant local synchronization of user preferences and thresholds.

## 🛠️ Tech Stack

- **UI**: SwiftUI
- **Persistence**: SwiftData
- **Location & Sensors**: CoreLocation
- **Audio**: AVFoundation
- **Platform**: iOS 17.0+
